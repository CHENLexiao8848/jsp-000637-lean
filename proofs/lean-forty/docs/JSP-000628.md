# JSP-000628 / Erdos 767

[Original problem](https://www.erdosproblems.com/767).

## Complete scope

For all positive k and n >= 3k+3, the extremal edge count of an n-vertex graph avoiding a cycle with k incident chords is (k+1)n-(k+1)^2. Both upper bound and attainment are proved; the arbitrary cycle vertex formulation is verified equivalent.
