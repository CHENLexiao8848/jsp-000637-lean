# JSP-000672 / Erdos 815

[Original problem](https://www.erdosproblems.com/815).

## Complete scope

Arbitrarily large n-vertex graphs have exactly 2n-2 edges and every proper induced subgraph has minimum degree <=2, yet have no 23-cycle. This fully negates the eventual all-cycle-length conjecture; the open even-length variant is not claimed.
