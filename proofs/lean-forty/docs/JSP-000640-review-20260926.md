## Mathematical solution, statement and scope

N. Alon, P. Frankl and L. Lovász, *The chromatic number of Kneser hypergraphs*, Transactions AMS 298(1) (1986), 359–370, [DOI](https://doi.org/10.1090/S0002-9947-1986-0857448-8), [complete published paper](https://web.math.princeton.edu/~nalon/PDFS/Publications/The%20chromatic%20number%20of%20Kneser%20hypergraphs.pdf). Theorem **1.1, printed p.359**; overview and multiplicative reduction **§2, pp.360–361**, including Proposition 2.3; full topological proof **§§3–4, pp.362–365**. Printed pagination differs from the PDF cover-page index.

For natural n,k and positive r,t, every coloring of all r-subsets of an n-element set with t colors contains k pairwise disjoint r-edges of one color whenever n≥kr+(t−1)(k−1). Equality in the threshold, composite k, and the separately proved k=0 and k=1 cases are included.

The entry explicitly supplies an injective edge-indexing map, each edge’s cardinality r, pairwise disjointness and one common color. Injection follows from disjointness and r>0, rather than an extra assumption. The exported endpoints prove the forcing direction, without claiming the lower coloring or sharpness below the threshold. The full upstream proof includes the finite Z/p Tucker lemma, the proved prime resolution and the multiplicative induction; no prime-resolution or topological lemma remains an unproved caller assumption.

The original theorem reduces the general matching multiplicity to prime factors using its multiplicative reduction, and establishes each prime case through the equivariant topological argument. The retained Lean development uses a finite Z/p Tucker formulation and supplies the corresponding proved prime case before strong induction. This is a complete attributed proof organization for the original forcing statement, not a claim of an independently discovered argument or literal transcription of every paper paragraph.

This is the proposed correspondence with [Erdős Problem 780](https://www.erdosproblems.com/780). No approved challenge version or independent referee approval is asserted. Complete mathematical and formal-statement review remain pending.

```lean
import ErdosProblems.Erdos780

/-! JSP-000640 / Erdős 780: the Alon–Frankl–Lovász matching theorem.
The proof is the pinned public plby formalization. The adapter exposes the
matching as actual finite subsets and explicitly proves distinctness. -/

namespace LeanForty.Problem000640

theorem monochromatic_matching {n k r t : ℕ} (hr : 1 ≤ r) (ht : 1 ≤ t)
    (hn : k * r + (t - 1) * (k - 1) ≤ n)
    (c : Erdos780.Edge n r → Fin t) : Erdos780.HasMonoMatching c k :=
  Erdos780.erdos_780 hr ht hn c

/-- All selected edges have exactly r vertices, are pairwise disjoint,
have the same color, and are distinct. No restriction to fixed parameters. -/
theorem distinct_monochromatic_edges {n k r t : ℕ} (hr : 1 ≤ r) (ht : 1 ≤ t)
    (hn : k * r + (t - 1) * (k - 1) ≤ n)
    (c : Erdos780.Edge n r → Fin t) :
    ∃ color : Fin t, ∃ e : Fin k → Erdos780.Edge n r,
      Function.Injective e ∧ (∀ i, c (e i) = color) ∧
      (∀ i, (e i).1.card = r) ∧
      ∀ i j : Fin k, i ≠ j → Disjoint (e i).1 (e j).1 := by
  obtain ⟨color, e, hmono, hdisj⟩ := monochromatic_matching hr ht hn c
  refine ⟨color, e, ?_, hmono, fun i => (e i).2, hdisj⟩
  intro i j hij
  by_contra hne
  have hd := hdisj i j hne
  rw [hij] at hd
  have hempty : (e j).1 = ∅ := by simpa using hd
  have hcard := (e j).2
  rw [hempty, Finset.card_empty] at hcard
  omega

end LeanForty.Problem000640
```
