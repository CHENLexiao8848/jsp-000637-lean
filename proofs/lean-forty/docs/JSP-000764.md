# JSP-000764 / Erdos 920

[Original problem](https://www.erdosproblems.com/920).

## Complete scope

For every k>=4, n^(1-1/(k-1))/(log n)^2 = O(f_k(n)) for the maximum chromatic number of a K_k-free n-vertex graph, eventually for all n. Projective construction, container bound, sampling, Ramsey bridge and inversion are discharged; the real-exponent interface is explicit. Exact finite values and stronger background variants are not claimed.
