# JSP-000658 / Erdos 801

[Original problem](https://www.erdosproblems.com/801).

## Complete scope

For every n >= 2^(2^11), every n-vertex graph with independence number <= floor(sqrt(n)) contains S with |S| <= floor(sqrt(n)) and floor(sqrt(n))*floor(log_2(n)) <= 2^24*e(G[S]). This gives the original asymptotic result, with explicit constants.
