# JSP-000660 / Erdos 803

[Original problem](https://www.erdosproblems.com/803).

## Complete scope

The absolute-constant regularization conjecture is false. For any proposed epsilon>0 and D>=1, some fixed m admits counterexamples of arbitrarily large n with at least n log n edges; every balanced m-vertex subgraph fails the epsilon*m*log(m) bound. Arbitrary subgraphs are quantified.
