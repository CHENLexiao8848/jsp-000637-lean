# JSP-000248 / Erdős 292

Original question: [Erdős 292](https://www.erdosproblems.com/292). Official entry: [JSP-000248](https://github.com/TheJustinSunPrize/awards/blob/82be4c4913b8fe394d68d1391f4c221fde947211/problems/catalog-0201-0300.md#JSP-000248).

For a natural n, Attainable(n) means there is a finite set S of integers in [1,n], with n in S and sum(1/m for m in S)=1 in the rationals. Distinctness is supplied by Finset; zero is excluded by the interval. The empty set cannot represent 1.

JSP000248.solution states that the real count of attainable n in [0,N), divided by N, tends to 1 as N tends to infinity. This answers the original density-one question for the entire set, not only a finite obstruction test or selected family. It does not claim Martin's stronger quantitative error term.

Proof: [LeanTwenty/JSP000248.lean](../LeanTwenty/JSP000248.lean). Underlying theorem: Erdos292.erdos_292. [README](../README.md), [ATTRIBUTION](../ATTRIBUTION.md), and [prior verification](../evidence/JSP-000248/verification.json) include the complete dependency recipe and exact axiom evidence.

Run from the batch directory: python scripts/verify.py --problem JSP-000248 --fetch-cache.
